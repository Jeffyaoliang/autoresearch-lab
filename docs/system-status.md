# 系统状态与证据等级

更新时间：2026-10-17。状态依赖私有 Research Control 报告，未在本公开代码库内独立复现。

| 组件 | 证据等级 | 说明 |
| --- | --- | --- |
| ResourceProbe 只读探测链路 | **真实端到端（私有环境）** | 沙箱请求 → AFS 队列 → 正常容器 Supervisor → 资源快照 → 自动绑定；一次新请求从 PendingExecutor 到 Completed |
| 4×H100 环境探测 | **真实现场** | 报告显示设备 UUID 与当前容器一致；个人存储配额和准确平台到期接口未被自动核实 |
| Codex 会话持久化 | **已部署并部分验证** | AFS 备份及恢复流程；不代表所有历史会话均可恢复 |
| Campaign 级授权 | **回归测试** | 允许单次授权范围内的测试、训练、重试和恢复；尚未通过完整的长期自治执行验收 |
| GPU Worker / checkpoint | **历史 smoke** | 存在单卡执行与独立进程恢复验证；不能等同于当前四卡配方完整恢复 |
| micro32 四卡 Engineering Campaign | **未执行** | 运行前因 AFS 个人目录容量不足而停止；GPU-hours 为零 |
| 容器开机自动 Bootstrap | **当前容器手动真实恢复** | 新容器自动触发仍需自然续建测试 |
| 外部容器自动复制续建 | **规划中** | 未声称具备 24/7 跨实例持续执行 |
| AutoResearch Eval Benchmark | **研究提案** | 尚未发布数据集、标注或评测结果 |

## 重要原则

- 真实运行、回归测试、模拟与计划必须明确区分。
- GPU 设备可见不等于已获得平台生命周期或存储配额认证。
- 运行失败先分类：科学、工程、环境或证据不足。
- 不因制作 GitHub 展示而中断私有环境的实际科研工作。

## 下一步验证

完成一个受控、已授权的真实 GPU Campaign，核对预算、日志、checkpoint 与故障恢复；之后再根据权属、保密和脱敏要求选择可共享案例。
